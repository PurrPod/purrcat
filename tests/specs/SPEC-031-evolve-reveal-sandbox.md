# SPEC-031：进化工厂沙盒目录「查看文件」

## 背景

技能与传感器的详情页原本内嵌文件编辑区，与宿主其它页面割裂；且合并审查需要展示 Diff。
改为详情页直接展示评测页，文件改到系统文件管理器里查看，合并只需一个「批准合并」动作。

## 行为

- 技能 / 传感器详情页默认展示评测（体检）结果，不再提供内嵌文件编辑与 Diff。
- 详情页右上角提供「查看文件」按钮，调用 `POST /api/evolve/reveal` 在系统文件管理器中打开对应沙盒工作区目录。
- 同一位置提供「批准合并」，把该沙盒并入正式库。
- 目录不存在时返回 404，不尝试启动文件管理器。

## 验收标准

- [ ] AC-1：`resolve_workplace_dir` 按类型返回 `<agent_vm>/<type>_workplace/<workplace_id>`，并拒绝含路径分隔符的标识。
- [ ] AC-2：`POST /api/evolve/reveal` 打开目录并返回 `{ok, path}`；目录缺失返回 404。
- [ ] AC-3：技能 / 传感器详情页不再渲染文件编辑与 Diff，默认为评测视图。

## 非目标

- 不改变 MCP / Graph / AgentLoop 的详情布局。
- 不调整合并接口本身（`POST /api/evolve/handle`）。

## 测试矩阵

| 层级 | 位置 | 覆盖的验收标准 |
| --- | --- | --- |
| L0 | `tests/l0/test_evolve_reveal.py` | AC-1、AC-2 |
| L1 | `tests/l1/test_api_routes_contract.py` | AC-2（路由契约） |

## 风险与回滚

- 仅在服务端主动调用系统命令打开目录；失败时返回 500 并提示。
- 前端仅新增两个右上角动作，回滚时删除路由与按钮即可。
