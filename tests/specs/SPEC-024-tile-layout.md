# SPEC-024：极简 UI 容器式 / 平铺式布局

## 背景

极简模式当前只有一种布局：左侧列表位、右侧会话位、中栏单例面板容器（标签页 + 右缘拖宽）。
面板数量增加时只能挤在同一个容器里切换标签，无法并排对照。需要一种可横向滚动的平铺布局，
让列表位、已打开的面板插件、会话位各占一个独立窗口，按需开合、排序与改宽。

## 行为

- 设置页 → UI 插件 → 「界面布局」提供模式选择：容器式（默认）/ 平铺式，切换即时生效。
- 容器式：完全保持现有行为（列表位 | 中栏面板容器 | 会话位，面板容器带标签页与总开关）。
- 平铺式：
  - 不再渲染中栏面板容器外壳与标签条，白条上的「面板容器」区域图标与设置分组一并隐藏。
  - 列表位、每个已打开的面板插件、会话位各是一个独立窗口，排成一条横向窗口条；
    窗口固定宽度、互不压缩，超出视口时横向滚动（底部细滚动条 / 滚轮 / 空白处拖拽平移）。
  - 窗口不设宿主标题条，插件内容占满窗口。按住 Shift 进入窗口管理：
    左右拖动调整顺序，拖拽期间窗口临时改为视口定位，始终咬住指针（跨屏滚动也不脱离、不被滚动容器裁剪）；
    同时在将要插入的分界处显示一条竖线指示，松手才按该位置落位；
    向下拖过窗口高度一半后松开即关闭该窗口。
  - 拖窗口右缘可改宽，宽度按窗口持久化，最小 260px。
  - 窗口条最右侧固定一个「+」窗口：点开后列出列表位、会话位与全部面板插件，
    点击即开/关；已打开的项标注「已打开」。
  - 窗口顺序默认按开启时间从左到右排列：关闭后从顺序表移除，再次打开追加到最右端；
    Shift 左右拖动仅在当前开启集合内临时调整顺序。白条/设置里关闭插件时窗口立即消失。
  - 窗口顺序与宽度持久化到 webminConfig.layout；刷新后恢复。

## 验收标准

- [ ] AC-1：后端 `/api/webmin/manifest` 返回 `layout`（mode/order/widths 已归一化）；
      `PUT /api/webmin/config` 接收并归一化 `layout`，非法值不落盘。
- [ ] AC-2：设置页可在容器式 / 平铺式之间切换，切换后界面按对应布局重建。
- [ ] AC-3：平铺模式下不再出现面板容器外壳、标签条、中栏分隔条与「面板容器」区域图标。
- [ ] AC-4：平铺窗口条默认按开启时间从左到右排列（列表位/会话位开启即入表，面板插件打开时间决定位置），
      横向滚动、可拖右缘改宽；Shift + 左右拖跟手排序、Shift + 向下拖过半关闭；
      顺序与宽度在重载后保持。
- [ ] AC-5：平铺模式下插件开/关（面板插件、列表位、会话位）统一由「+」窗口管理；
      从白条或设置关闭固定位插件时，对应窗口立即移除，不留空白占位。
- [ ] AC-6：内置浏览器在平铺布局滚动/改宽/重排后收到 `host.layoutChanged` 并同步原生视图。

## 非目标

- 不做多显示器 / 多工作区 / 垂直平铺。
- 不改容器式布局的既有行为与样式。
- 不让第三方 panel-container 插件参与平铺模式。
- 不引入窗口重叠 / 自由浮动（窗口始终在横向条内首尾相接，仅拖拽期间跟手位移）。

## 风险与回滚

- 平铺模式会重挂载 iframe（切换模式时），插件内存状态可能丢失；在平铺模式内部
  排序/改宽不重挂载。
- 布局配置缺省或损坏时回落到容器式，旧配置（无 layout 分节）行为不变。
