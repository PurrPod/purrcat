# SPEC-036 应用级提醒与未绑定事项处理

## 背景

随手记（builtin-note）里的事项可以不绑定 Worker（`purrcat@none`）。这类事项到点时，
目前没有任何反馈：`ui:note` 的 SSE 只有随手记面板打开时才能收到，面板关闭就被丢掉。
另外「立即执行」在未绑定时只弹一句「请先绑定 Worker」，与用户「这件事我已经做完了」的预期不符。

## 目标

1. 宿主向所有插件暴露应用级弹窗 API。
2. 未绑定事项到点由宿主弹出提醒，不依赖随手记面板是否打开。
3. 未绑定事项点击「立即执行」直接标记为 `DONE`。

## 验收标准

- [ ] AC-1：插件调用 `dialog.message`（`{title, description?, options?, dismissible?}`）弹出应用级弹窗；
  返回 `{option}` 为被选中的选项 id，取消 / Esc / 点遮罩返回 `{option: null}`。
- [ ] AC-2：弹窗是宿主级 DOM 遮罩，任何插件都能看到；出现时触发 `host.nativeCover`，
  关闭后恢复，原生视图不会被遮罩压住。
- [ ] AC-3：`ui:note` 定时事件 `fired` 时宿主弹提醒（标题含时间与事项名、描述为事项描述），
  同一事件重复投递只提醒一次；随手记面板是否打开不影响提醒。
- [ ] AC-4：提醒提供「打开随手记 / 知道了」，选择「打开随手记」直接激活 `builtin-note` 面板。
- [ ] AC-5：未绑定 Worker 的卡片点击「立即执行」后置为 `DONE`、写入 Markdown，并取消该事项当天的原定定时。

## 非目标

- 不做系统级通知（Electron Notification）与声音提醒。
- 不做提醒的稍后重发 / 自定义延后时间。
