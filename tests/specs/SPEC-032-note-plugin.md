# SPEC-032 笔记插件（Note）

## 背景

极简模式需要一个按日期归档的 Markdown 记录面板：顶部是当天时间线与进度（放在可收起的抽屉里），正文支持
Obsidian 式行内实时渲染，并能把时间段转成可执行的 TODO 卡片。

## 行为

- 新增内置 UI 插件 `builtin-note`（`slot.area = panel`），按日期归档：每天一份 Markdown，存放在 `~/.purrcat/notes/<YYYY-MM-DD>.md`；当天内容为空时不落盘，清空后删除文件。不再支持切换文档。
- 顶部所有信息（日期、剩余进度、时间线）放在一个抽屉里，抽屉拉手固定在抽屉下沿；收起后只剩拉手，正文占满剩余高度，展开状态记在本地。右上角是保存状态与两个图标按钮：设置（打开设置中心）、刷新。
- 左上角日期可点击，弹出日期选择器与已归档日期列表；选择后加载对应日期的归档，切换前先保存当前内容。跨零点时若正在看今天，自动切到新的一天。
- 主题在插件配置里选择浅色 / 暖色 / 暗色（默认暖色），切换后立即作用到整个笔记面板；设置按钮打开宿主设置中心的 UI 插件页，可直接改。
- 时间线展示当天起床到睡觉的时间窗与文档内卡片：轨道是 6px 细线，当前时刻右侧与睡觉时段只把轨道本身置灰，不画整条灰带。
  当前时刻只用一个圆点标记；起床时间点标太阳图标、睡觉时间点标月亮图标，二者与圆点一样嵌在轨道上，鼠标悬浮显示对应时间。
- 在时间线上按住并拖动到另一个时间点，松开后弹出事项名称输入框；确认后向文档追加：

  ````
  ```purrcat@none
  - TODO hh:mm~hh:mm Nmin
  # 事项名称
  无描述
  ```
  ````

- 正文是一个连续的 Markdown 笔记编辑器（单栏实时预览，不是按块编辑的 HTML 编辑器）：文档按行切分编辑单元，
  光标所在单元显示原始 Markdown 源码，其余单元渲染；标题/列表/引用渲染时隐藏标记，空行保留可点击的落点。
  点击任意一行把光标放到点击位置（按渲染文本到源码偏移映射），按 `Esc` 或点击笔记以外的区域回到渲染态；
  多行选区单击收起后，只保留光标所在行处于源码态，其余行立即回到渲染态。
- 拖拽/双击先走浏览器原生选区，标题、列表与正文可以跨行一起选中；复制始终输出 Markdown 源码，
  跨行选区补全整行（保留 `#`、列表符号与围栏）。松开鼠标时把选区映射回源码，落进同一个源码编辑区，
  之后的输入、IME 与删除都由原生编辑处理。卡片/代码块/表格内部的选区保持原生，不会把整块展开成一行源码。
- 编辑行与渲染行外观一致，只有光标，没有选中框；单行单元按一次回车就在光标处拆成新行并把光标落到新行行首；
  卡片/代码块/表格整段进入源码编辑，内部回车正常插入新行，上下方向键在首尾可以走出结构。
- `purrcat@<target>` 代码块渲染为圆角卡片：第一行是 `TODO` 勋章 + 标题 + 时间段，右上角是时长；
  第二行起是描述正文，与卡片左缘对齐。勋章沿用 agent-deck 的 Logseq 关键词样式（虚线圈图标 + 加粗 `TODO`）。
- 时长按长度取绿 / 琥珀 / 红三档：≤30min 绿、31–60min 琥珀、>60min 红。
- 点击 `TODO` 勋章打开 Worker 绑定弹窗（不绑定 / main 主会话 / background），保存后写回围栏首行；
  已绑定的勋章显示为黄色 `WAITING`，再次点击可改绑或取消绑定；卡片首行的 `- TODO` 关键字同步改为
  `- WAITING`（执行中 `RUNNING`、完成 `DONE`、失败 `ERROR`、取消绑定回 `TODO`），解析时关键字不影响时间段与标题。
- Worker 绑定弹窗只提供三种去向：不绑定 / `main` 主会话 / `background`（默认图 `default`）；
  旧笔记里的自定义图名仍保留为「旧图」选项。
- 绑定弹窗提供「立即执行」：保存绑定的同时跳过定时直接派发。background 走 `POST /api/tasks/run`
  （`graph_name=default`，`inputs.prompt` 为标题 + 描述），main 走 `POST /api/timer/events`
  （source 为 `note-run:<date>`，消息里附来源插件、笔记文件路径与 skill 名）；手动执行后取消该卡片原本的定时。
- background 派发成功后把任务 ID 写进围栏：`purrcat@default/<task_id>`；加载或刷新时扫描到这个引用就自动
  监听 `/api/tasks/{id}/state`、`/elapsed`、`/token`，无需依赖本地缓存。耗时由 Task 自己维护。
- 派发后勋章变为橙色 `RUNNING`（字母逐个跳动），卡片底部实时显示耗时与 token 消耗；
  任务完成变绿色 `DONE` 且勋章不可再点击（避免二次派发），失败变红色 `ERROR`。执行状态按日期保存在 `purrnote.runs.<date>`，
  刷新或切换日期后恢复；任务状态、耗时与 token 通过 `/api/tasks/{id}/state`、`/api/tasks/{id}/elapsed`、
  `/api/tasks/{id}/token` 轮询。
- 主库提供 `purrcat-note` skill（`~/.purrcat/skills/purrcat-note/SKILL.md`），说明插件用途、卡片格式、main/background 派发方式，
  以及如何让卡片实时展示任务进度与耗时。
- 卡片向左滑动露出垃圾桶；点击垃圾桶先在卡片上划一道线，动画结束后从 Markdown 中删除整个 `purrcat` 代码块。
- 起止时间与主题保存在插件配置；时间线条目不再单独保存，直接从当前文档的 `purrcat` 卡片派生（时间段合法的卡片才会出现在时间线上）。
- 保存文档后把当天（仅今天）开始时间不早于当前时刻 60 秒前的卡片同步到定时任务中心：`main` 投给 Agent，graph 名投给对应工作流，`none` 通过 `ui:note` 提示；到点事件经 `/api/timer/stream` 推送，Note 以 toast 提示。

## 验收标准

- [ ] AC-1：时间线进度按起床/睡觉时间窗计算，支持跨午夜，窗外显示 0% / 100%。
- [ ] AC-2：拖拽比例与时间点可互转，拖拽生成的块严格符合 `- TODO hh:mm~hh:mm Nmin` + `# 名称` + 描述的三行格式并追加在文档末尾。
- [ ] AC-3：`purrcat@...` 块可解析出 target/时间段/时长/标题/描述（标题也可写在 TODO 行），改写目标只动围栏首行，正文不变。
- [ ] AC-4：行单元切分能区分标题、列表、引用、分隔线、表格、代码块、卡片与空行，并给出准确行范围，供行内编辑替换；卡片内部任意行都归属整个卡片单元。
- [ ] AC-5：插件清单可被内置扫描器识别，入口、纯逻辑 `core.js` 与 `marked` 共享依赖齐备。
- [ ] AC-6：渲染文本偏移能映射回源码偏移（跳过标题、强调等 Markdown 标记），保证点击行内文本落点正确。
- [ ] AC-7：卡片左滑露出垃圾桶，删除时先播放划线动画再从源码移除整个块，其余内容与空行保持不变。
- [ ] AC-8：跨行拖选后高亮补全为整行并映射为源码选区，复制得到完整 Markdown 源码（含 `#`、列表符号、围栏）；在选区上输入能替换这些行。
- [ ] AC-9：时间线在起床时间点显示太阳图标、睡觉时间点显示月亮图标，修改配置中的时间后图标随之移动。
- [ ] AC-10：笔记按日期归档到 `~/.purrcat/notes/<date>.md`；空白内容不落盘/删除文件；日期选择器可查看历史归档，不再提供换文件入口。
- [ ] AC-11：时间线只由当前文档中带合法时间段的卡片派生；保存后当天卡片同步到定时任务中心，到点事件能在面板内提示。
- [ ] AC-12：绑定后立即显示 `WAITING`，卡片首行关键字同步为 `- WAITING`；「立即执行」直接派发并进入 `RUNNING`
  （字母逐个跳动），关键字同步 `- RUNNING`；卡片底部实时更新耗时与 token，完成后 `DONE` 且勋章禁用、失败 `ERROR`；
  执行状态按日期持久化并可在刷新后恢复。
- [ ] AC-13：Worker 只提供 main / background（默认图）；background 派发后围栏写入 `purrcat@default/<task_id>`，
  重新加载时扫描该引用即可恢复任务监听；耗时来自 `GET /api/tasks/{id}/elapsed`，不依赖前端本地计时。
  main 派发的消息包含来源插件、笔记文件路径与 `purrcat-note` skill 名。

## 非目标

- 不做多文件笔记库、目录树、双链、标签、附件与全文检索。
- 不做完整富文本编辑器；列表等复杂块以整块源码编辑形式呈现。
- 不做笔记云同步与多端合并；归档只保存在本机 `PURRCAT_DIR`。
- 会话与任务复用既有接口；笔记读写使用 `/api/note`，定时同步使用 `/api/timer`。

## 风险与回滚

- 时间线是文档卡片的派生视图，删除卡片会同步从时间线消失；历史日期不参与定时调度。
- 行内编辑以行为单元，表格与代码块整段进入源码编辑；复杂嵌套 Markdown 的呈现弱于 Obsidian，但不会破坏原文。
- 预览先转义原始 HTML 再走 `marked`，避免笔记内容在宿主同源 iframe 中执行脚本。
- 回滚：删除 `ui/web-minimal/plugins/builtin/builtin-note/`、`src/server/api/note.py` 与对应 L0/L1 用例；定时事件由 `/api/timer` 统一回收。
